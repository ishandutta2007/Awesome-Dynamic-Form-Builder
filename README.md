# Awesome-Dynamic-Form-Builder

# Top Dynamic Form Builder Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Form Design, Logic Branching & Data Collection*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Dynamic Form Builders**. These tools enable organizations to create intelligent, logic-driven forms without coding — with conditional branching, multi-step workflows, validation rules, and seamless data integration.

**Examples** include Salesforce Dynamic Forms, Typeform, Jotform, Formstack, Fillout, Feathery, Paperform, Wufoo, Cognito Forms, and 123FormBuilder (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom form logic, and open data collection — ideal for developers, product teams, and organizations seeking transparent, vendor-independent form infrastructure.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Salesforce Dynamic Forms](https://www.salesforce.com/)**  
  Native Salesforce feature for building dynamic record pages with conditional field visibility. Enables admins to show/hide fields based on record data without custom code.

- **[Typeform](https://www.typeform.com/)**  
  Conversational form builder known for engaging, mobile-friendly experiences. Features logic jumps, hidden fields, and extensive integrations.

- **[Jotform](https://www.jotform.com/)**  
  Form builder with drag-and-drop editor, conditional logic, payment integrations, and 10,000+ templates.

- **[Formstack](https://www.formstack.com/)**  
  No-code form builder with conditional logic, workflow automation, and document generation.

- **[Fillout](https://www.fillout.com/)**  
  Flexible form builder with advanced logic, scheduling, payments, and native integrations with Airtable, Notion, and Google Sheets.

- **[Feathery](https://www.feathery.io/)**  
  API-first form builder for developers. Features complex logic, dynamic data, and full customization via SDK.

- **[Paperform](https://paperform.co/)**  
  Form builder blending documents with forms. Features dynamic calculations, conditional logic, and payment processing.

- **[Wufoo](https://www.wufoo.com/)**  
  Classic form builder with drag-and-drop editor, conditional logic, and reporting.

- **[Cognito Forms](https://www.cognitoforms.com/)**  
  Form builder with calculated fields, conditional logic, and workflow automation.

- **[123FormBuilder](https://www.123formbuilder.com/)**  
  Form builder with conditional logic, payment integration, and multi-language support.

## Open-Source GitHub Projects

- **[Formbricks](https://github.com/formbricks/formbricks)**  
  Leading open-source survey and form platform (AGPL-3.0) positioned as an open-source Qualtrics alternative. Features no-code survey builder with multiple question types, targeted in-app/website/link/email surveys, contact management, and powerful integrations (Slack, Notion, Zapier, n8n). Self-hostable via Docker or Kubernetes. Privacy-first with full data ownership .

- **[OpnForm](https://github.com/OpnForm/OpnForm)**  
  Open-source form builder (AGPL-3.0) for creating beautiful, customizable forms with unlimited submissions. Built with Laravel 11 API and Nuxt 3 frontend. Features no-code drag-and-drop builder, conditional logic, file uploads, signature pad, QR code scanner, custom themes, and integrations with Slack, Discord, Zapier, and Google Sheets. Supports 30+ languages and self-hosting via Docker .

- **[SurveyJS](https://github.com/surveyjs/survey-library)**  
  Free JavaScript form builder library (MIT) with integration for React, Angular, Vue, and Knockout. Renders dynamic JSON-based forms, multi-step wizards, quizzes, and scored assessments. Features 20+ input types, conditional logic, validation, partial submissions, and multi-language support. Survey Creator provides drag-and-drop form building with CSS theme editor .

- **[FlexForms](https://github.com/biohackerellie/flexforms)**  
  Easy-to-use form builder application (license varies) with intuitive drag-and-drop form creation. Frontend built with React and DNDKit, bundled into a single Go binary for zero-dependency deployment. Features secure authentication, end-to-end encryption of form data, GDPR compliance, and SQLite/PostgreSQL backends. Docker images available .

- **[Budibase](https://github.com/Budibase/budibase)**  
  Open-source low-code platform (GPL-3.0) with powerful form building capabilities. Forms support create/update/view modes, schema-driven field generation, validation, custom inputs, and multi-column layouts. Form blocks auto-generate forms from database schemas .

- **[Baserow](https://github.com/baserow/baserow)**  
  Open-source no-code database tool (MIT) with built-in Form view. Transforms table structure into shareable web forms that create rows directly in the database. Features conditional logic, URL pre-filling, file uploads, branding customization, and post-submission redirects .

- **[Variant Form](https://github.com/vform666/variant-form)**  
  Low-code platform for building dynamic, data-driven web forms (license varies). Visual drag-and-drop designer, runtime rendering engine, schema-based validation, and JSON configuration. Supports Vue integration with component configuration and live preview .

- **[Formkl](https://github.com/imrim12/formkl)**  
  Open-source DSL (Domain-Specific Language) to define and create form schemas (license varies). Designed to be simple, consistent, and highly readable as natural language .

- **[pgkiln](https://github.com/pgkiln/pgkiln)**  
  Low-code, SQL-driven application builder for PostgreSQL (license varies), modeled on Oracle APEX. Pages, regions, items, buttons, validations, and processes are rows in a meta schema. Features form pages generated from tables, MCP server for AI coding agents, and progressive web app support .

- **[Bootstrap Form Builder](https://github.com/minikomi/bootstrap-form-builder)**  
  Low-code web form generator (license varies) enabling creation of data collection interfaces with Bootstrap styling .

### Additional Strong Open-Source Options

- **[Vue Form Making](https://github.com/gavinzhulei/vue-form-making)** — Visual form designer for Vue.js (license varies) generating runnable code and JSON .
- **[form-create](https://github.com/xaboy/form-create)** — JSON-driven form generator and low-code form builder (MIT) for dynamic web forms .
- **[Form.io](https://github.com/formio)** — Open-source form and API building platform (MIT) with drag-and-drop builder.
- **[React Reactive Form](https://github.com/bietkul/react-reactive-form)** — Angular-like reactive forms in React (MIT).
- **[JSON Schema Form Element](https://github.com/json-schema-form-element/jsfe)** — Custom Element that auto-generates forms from JSON Schema (MIT).
- Community **n8n** workflows for form submission automation and data routing.

**Frameworks for building custom systems**: Combine **Formbricks** or **OpnForm** as the form engine with **SurveyJS** for embedded form rendering, **Budibase** for internal data collection apps, and **PostgreSQL** for submission storage — creating a fully self-hosted, enterprise-grade dynamic form platform.
